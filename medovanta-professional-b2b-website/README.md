## Before publishing
1. Open index.html.
2. Replace every `91XXXXXXXXXX` with your real WhatsApp number including country code.
   Example: 919876543210
3. Replace placeholder email/phone text in the company profile PDF if required.
4. Replace the Google Maps location with your exact office/warehouse address once finalised.

## GitHub Pages
Repository can be published from:
Settings -> Pages -> Deploy from a branch -> main -> / (root)

This is a static website; no server or database is required.
